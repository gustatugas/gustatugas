### ⏱️ Pomodoro — Foco e Produtividade

Temporizador Pomodoro com lista de tarefas e registro do tempo de estudo do dia, sobre um plano de fundo em pixel art. Feito com HTML, CSS e JavaScript puro.

- Foco e descanso configuráveis, com pausa, retomada e reinício
- O timer continua certo mesmo ao recarregar a página
- Tarefas e histórico salvos no `localStorage`
- Layout responsivo para desktop, tablet e celular

🔗 [Ver online](https://pomodoro.gustavo-b-souza002.workers.dev/) · [Código no GitHub](https://github.com/gustatugas/Pomodoro)
